# Voice Typer

Локальная голосовая диктовка в активное окно через faster-whisper (Whisper `tiny`).

## Запуск

`run.bat` — создаст venv, поставит зависимости, запустит без консоли. Иконка появится в трее (правый нижний угол, может быть скрыта за `˄`).

## Использование

1. Курсор в любое текстовое поле
2. **F12** — высокий бип, запись пошла
3. Говори
4. **F12** — низкий бип, текст распознан и напечатан

`Numpad 0` тоже работает как альтернатива.

## Трей-меню

- **Включен** — вкл/выкл реакцию на хоткей
- **Автозапуск (Windows)** — старт при входе в систему
- **Выход**

## Логи

`%USERPROFILE%\voice_typer.log`

## Кастомизация

В `voice_typer.py`:

- `MODEL_SIZE` — `"tiny"` / `"base"`
- `MIC_HINT` — подстрока имени нужного микрофона
- `TOGGLE_SCAN_CODES` — скан-коды блокируемых клавиш
